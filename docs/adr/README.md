# Architecture Decision Records

Short records of decisions that are expensive to reverse or that the owner chose between options.

## How to write one

1. Copy `0000-template.md` to `NNNN-kebab-title.md` with the next free number.
2. Fill in context, 2–3 options with pros and cons, and a recommendation. Status: `Proposed`.
3. Open a PR labeled `needs decision`. The owner picks an option in the review.
4. Record the choice and its reason, set status to `Accepted`, merge.

A decision that later changes gets a new ADR that supersedes the old one; the old one is not
rewritten.
